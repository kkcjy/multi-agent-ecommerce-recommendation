```bash
ECOM_DATABASE_URL=sqlite:///./ecommerce.db
```

- 向量服务：降级（返回空列表）
- 库存服务：降级（假设全部有货）

### 6.2 生产环境配置

```bash
# 1. 修改环境变量
ECOM_DATABASE_URL=mysql+pymysql://root:password@localhost:3306/ecommerce
ECOM_REDIS_URL=redis://localhost:6379/0
ECOM_MILVUS_HOST=localhost

# 2. 修改 AppContainer
class AppContainer:
    @property
    def product_repo(self) -> ProductRepository:
        if self._product_repo is None:
            self._product_repo = DatabaseProductRepository(
                db_url=self._settings.database_url
            )
        return self._product_repo
```
